## 附录 E：Agent 10 大反模式与架构级治理全景速查表

| 反模式名称 (Anti-Pattern) | 典型危险表象 | 工业级系统危害 | 架构级治理对策 (Solution) |
| :--- | :--- | :--- | :--- |
| **1. 饥饿工具全量灌入** | 将 500 个 API JSON Schema 一次性塞入 Prompt | 上下文占满，注意力严重稀释，准确率暴跌 | 引入 **惰性工具（Lazy Tools）** 与两阶段动态路由 |
| **2. 黑盒直接裸机执行** | 允许模型在生产宿主机上直接敲 root Bash | 误删根目录或格式化磁盘，毁灭性数据损失 | 强制使用 **Firecracker MicroVM / Docker 沙箱** |
| **3. 全量文件盲目重写** | 改 1 行代码让模型重写整个 2000 行文件 | 模型偷懒省略代码导致业务损毁，浪费 Token | 强制使用 **`replace_file_content` 单块替换** |
| **4. 进程内无序使用 `cd`** | 工具内部执行 `cd ..` 改变全局进程目录 | 破坏并发隔离，引发文件路径全盘错乱 | 绝对禁止 `cd`，显式传递 `Cwd` 执行基准路径 |
| **5. 意图猜测式编程** | 需求模糊时模型“脑补”业务逻辑并直接写代码 | 严重偏离用户意图，造成巨大无意义返工 | 强制唤醒 **`ask_question` 交互模态中断** 对齐 |
| **6. 忽略非零退出码** | 工具报错后大模型视而不见，直接进入下一步 | 幻觉级联，错误在后续步骤中呈指数级扩散 | 强制 **L0 状态机单测门禁**，未过测试禁止推进 |
| **7. <100 技能强上向量检索**| 只有 20 个技能却大费周章搭建向量库检索 | 余弦相似度高维碰撞，关键技能严重错选漏选 | **语义描述常驻 + 渐进式披露（Progressive Disclosure）** |
| **8. 缺乏指纹的死循环** | 遭遇权限不足时在同一行代码反复试错数十次 | 陷入自激震荡死循环，烧穿数千美元账单 | 引入 **动作指纹哈希（Action Fingerprint）** 熔断器 |
| **9. 提示词缓存前缀穿透** | 在 System Prompt 首部插入动态时间戳或随机会话 ID | KV Cache 命中率跌至 0%，账单暴涨 10 倍 | **时间戳坚决后置**，严格锁定静态基座前缀字节流 |
| **10. 缺乏快照原子回滚** | 代码改崩之后无法恢复，只能在破损上越改越乱 | 任务彻底不可救药，环境脏污不可逆 | 引入 **Git Shadow Worktree 事务快照与撤销机制** |
